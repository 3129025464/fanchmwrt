FWX REST API Documentation

FanchMWRT Enterprise Firewall REST API v1.0

Authentication

curl -X POST http://router/ubus -d '{"jsonrpc":"2.0","id":1,"method":"call","params":["00000000000000000000000000000000","session","login",{"username":"root","password":"PASSWORD"}]}'

Endpoints

fwx.status - System status
fwx.stats - Security statistics
fwx.alerts - Recent alerts
fwx.ddos_ban - Ban IP address
Params: {"ip": "x.x.x.x", "duration": 3600}
fwx.ddos_unban - Unban IP address
Params: {"ip": "x.x.x.x"}
